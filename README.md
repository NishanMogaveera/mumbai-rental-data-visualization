# 🏠 Mumbai Rental Data Visualization

A Python-based data visualization project that analyzes rental property data from Mumbai using **Pandas, Matplotlib, and Seaborn**.

The project explores rental prices, property types, regions, localities, bedrooms, furnishing status, carpet area, and metro connectivity through different visualizations.

---

## 📌 Project Overview

Mumbai has a wide range of rental properties with significant differences in price depending on location, property size, number of bedrooms, furnishing, and other factors.

This project analyzes a Mumbai rental dataset and uses data visualization techniques to identify useful patterns and relationships in rental prices.

---

## 🎯 Objectives

- Analyze rental properties across different regions of Mumbai.
- Understand the distribution of properties across regions and tiers.
- Identify localities with higher average rental prices.
- Compare rental prices based on furnishing status.
- Analyze rental prices according to the number of bedrooms.
- Study the relationship between carpet area and monthly rent.
- Analyze correlations between numerical variables.
- Compare rental price distributions across different regions.
- Analyze locality-wise rent based on the number of bedrooms.
- Compare 2 BHK and 3 BHK rental prices across regions.
